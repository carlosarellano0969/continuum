# Deterministic demo evidence

The checked-in dataset is synthetic, non-sensitive, and generated by
`scripts/generate_demo_data.py` with seed `20260924`.

- `interactions.jsonl` contains 360 operational interactions under the demo
  organization and agent scope.
- `memories.jsonl` contains stable known-answer memory records derived from
  those interactions. They are review fixtures, not proof that embeddings were
  generated.
- `retrieval_cases.json` defines required, allowed-support, and forbidden memory
  IDs for three retrieval queries.
- `manifest.json` records the seed, counts, SHA-256 file hashes, observed lifts,
  evidence thresholds, and safety declaration.

The financing/pricing cohort demonstrates that fast financing information
outperforms deferred follow-up. The pricing-objection cohort demonstrates that
generic discount-first replies underperform needs-based pricing explanations.
Both are intentionally strong. The regional-partner-directory source cohort
has an apparent effect but no more than 12 interactions, so it is deliberately
insufficient for policy adaptation.

Regenerate only with the documented script; direct edits will fail the
byte-for-byte fixture acceptance check.
